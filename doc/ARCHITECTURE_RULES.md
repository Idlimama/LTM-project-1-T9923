# Architecture Rules
1. Preserve: evidence -> extraction -> specialist council -> bounded peer review -> deterministic gates -> human disposition.
2. Browser talks only to FastAPI. FastAPI owns state access.
3. Model output is advisory. Finance and hard gates are deterministic Python.
4. Every specialist uses typed input/output contracts.
5. Peer debate is bounded to one review pass in this build.
6. Hard gates cannot be negotiated away.
7. Persist completed evaluations and human dispositions.
8. Synthetic policies and synthetic cases must be labeled as synthetic.
9. Do not expose hidden chain-of-thought. Expose concise position, evidence, concerns, recommendations and peer response.
10. Future LangGraph, FAISS, regulatory packs and React UI must plug into these contracts instead of replacing the core path.
